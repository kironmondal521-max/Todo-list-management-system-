# To-Do List Management System

A simple and responsive To-Do List web application built using HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as completed or pending
- Delete tasks
- Filter all, pending, and completed tasks
- View total, pending, and completed task counts
- Save tasks in the browser using Local Storage
- Responsive design for desktop and mobile screens

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No additional installation is required.

## Project Files

- `index.html` - Structure of the application
- `style.css` - Design and responsive layout
- `script.js` - Application functionality and Local Storage
